# 💰 FinPilot

**FinPilot** is a simple expense tracker web application designed to help users record and manage their daily expenses.

This project is being developed as a **beginner web development project** while learning the fundamentals of web development step by step.

## 🎯 Project Objective

The main objective of FinPilot is to create a simple and easy-to-use platform where users can:

* Track their daily expenses
* View their expense history
* Manage their budget
* Understand their spending habits
* Work towards better financial management

## 🛠️ Technologies

Currently, this project is being developed using:

* HTML
* CSS

More technologies will be added as the project progresses.
